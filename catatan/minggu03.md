# Catatan Minggu 3: Inheritance

## Yang saya kerjakan
Yang saya kerjakan minggu ini lumayan banyak dibandingkan minggu-minggu sebelumnya. Saya ada ngelengkapin class Ruang, Laptop, AlatLab dari class Aset. Selain itu saya juga ada menambahkan data untuk nyimpan informasi aset, menambahkan kontruktor untuk ngisi data, menambahkan getter untuk ngambil data yang tersimpan, dan menambahkan method getJenis() untuk mengetahui jenis aset kek apakah untuk Ruang, Laptop, atau AlatLab.

## Keputusan desain
Saya pilih class Aset buat menyimpan data umum aset. Sedangkan kek class Ruang, Laptop, dan AlatLab itu ada pake beda-beda sesuai sama jenisnya.
